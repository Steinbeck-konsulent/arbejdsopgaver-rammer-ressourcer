# 3i1 – punkt 23

Et lille browserbaseret mikroforløb om sammenhængen mellem arbejdsopgaver, rammer og ressourcer.

## Filer

- `index.html` – appens indhold og fem trin
- `styles.css` – design og mobilvisning
- `app.js` – flow, lokal lagring, opsamling og PDF-generering
- `steinbeck-mark.svg` – lille Steinbeck-mærke i footeren

## Data

- Svar gemmes lokalt i browserens `localStorage` undervejs.
- Appen har ingen database, login, analytics eller AI-kald.
- PDF dannes direkte i browseren.
- Brugeren kan slette alle lokalt gemte svar med **Nulstil** eller **Slet mine lokale svar**.

## GitHub Pages

Læg alle fire filer i roden af et GitHub-repository og aktivér GitHub Pages for repositoryets standardgren.

## Design

Versionen bruger en rolig grøn/orange palette med højere kontrast end den tidligere grå prototype. Afsenderen er bevidst lille og ligger kun i footeren.

## Afgrænsning

Ingen database, dashboard, AI-analyse, kalenderintegration eller automatisk mailafsendelse.
