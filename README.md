# Arbejdsopgaver, rammer og ressourcer

Et browserbaseret refleksionsforløb, der kan bruges til at uddybe svar fra en medarbejderundersøgelse og skabe et mere konkret grundlag for dialog om arbejdsopgaver, rammer og ressourcer.

Værktøjet er generisk og knytter sig ikke til en bestemt arbejdsplads, kommune eller undersøgelse.

## Filer
- `index.html` – selve forløbet
- `styles.css` – design og layout
- `app.js` – logik, lokal lagring og PDF-generering
- `ai-maerke.png` – det lille “Genereret med AI”-mærke

## Brug på GitHub Pages
Upload alle fire filer til roden af repository'et. `index.html` forventer, at de øvrige filer ligger i samme mappe.

## Data
Svar gemmes kun lokalt i browseren undervejs. Når PDF'en genereres, ryddes de lokalt gemte svar automatisk.

## Version
Denne samlede pakke indeholder de seneste rettelser til betingede spørgsmål og PDF-output.
